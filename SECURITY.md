# Security

- Никогда не публикуйте `settings.json` с настоящим VirusTotal API-ключом.
- По умолчанию программа не перемещает файлы, которые не прошли правило чистоты.
- Не отправляйте в публичный VirusTotal API конфиденциальные файлы.
- Для сообщений об уязвимостях создайте GitHub Security Advisory или Issue без публикации чувствительных деталей.
