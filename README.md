# VirusTotal Folder Checker

Лёгкое Windows-приложение для автоматической проверки файлов через VirusTotal.

## Что умеет программа

- Включать и выключать автоматическое сканирование.
- Выбирать папку, которую нужно проверять.
- Выбирать папку, куда переносить чистые файлы.
- Проверять один конкретный файл вручную.
- Проверять все файлы из выбранной папки вручную.
- Показывать живой лог прямо в интерфейсе.
- Показывать историю результатов и статистику.
- Очищать очередь ожидающих файлов.
- Не перезаписывать существующие файлы: автоматически добавляет `(1)`, `(2)` и т. д.
- Отдельно настраивать отправку неизвестных файлов в VirusTotal.
- При желании отправлять файлы, не прошедшие проверку, в папку карантина.
- Сохранять выбранные папки и настройки в `settings.json`.
- Работать без постоянного консольного окна.

## Первый запуск

1. Запустите `VirusTotalFolderChecker.exe`.
2. При первом запуске создастся `settings.json`.
3. Вставьте собственный API-ключ VirusTotal в `api_key`.
4. Запустите программу ещё раз.

Пример:

```json
{
  "api_key": "ВАШ_API_КЛЮЧ",
  "scan_folder": "notchecked",
  "clean_folder": "dowload"
}
```

Папки можно менять прямо в интерфейсе кнопками **«Выбрать папку проверки»** и **«Выбрать папку чистых»**.

## Интерфейс

### Автосканирование

Кнопка **«Автосканирование: ВКЛ/ВЫКЛ»** управляет постоянным мониторингом выбранной папки.

### Ручная проверка файла

**«Проверить файл»** открывает стандартное окно выбора файла. После чистой проверки программа спросит, нужно ли перенести файл в папку чистых.

### Проверить папку

**«Проверить папку»** добавляет все подходящие файлы из папки проверки в очередь.

### Живой лог

Справа отображаются события программы в реальном времени. Полный лог также хранится в `virus_checker.log`.

### История

В левой части отображаются результаты последних проверок.

### Статистика

В интерфейсе показываются:

- количество проверенных файлов;
- количество чистых файлов;
- количество файлов, требующих внимания;
- количество ошибок;
- текущий размер очереди.

### Контроль приватности

Галочка **«Отправлять неизвестные файлы на анализ VirusTotal»** позволяет отключить автоматическую загрузку неизвестных файлов.

### Карантин

По умолчанию автоматический карантин выключен. При включении файлы, которые не прошли установленное правило чистоты, перемещаются в папку `quarantine`.

## Важное ограничение

Нулевая детекция VirusTotal не является абсолютной гарантией безопасности. Не запускайте неизвестные файлы только потому, что программа получила результат без обнаружений.

Обычная отправка неизвестного файла в публичную инфраструктуру VirusTotal не подходит для конфиденциальных данных.

## Сборка на Windows

Обычному пользователю Python не нужен. Для разработчика:

```text
build_windows.cmd
```

Скрипт установит зависимости, запустит тесты и соберёт:

```text
dist\VirusTotalFolderChecker.exe
```

## GitHub Actions

Workflow находится здесь:

```text
.github/workflows/build-windows.yml
```

Он:

1. устанавливает Python;
2. устанавливает зависимости;
3. запускает тесты;
4. собирает one-file Windows EXE;
5. публикует EXE как Artifact;
6. при создании тега `v1.0.0` автоматически создаёт GitHub Release.
